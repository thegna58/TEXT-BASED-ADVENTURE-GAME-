# TEXT-BASED-ADVENTURE-GAME-
Escape Room Riddle Game
This project is an interactive Escape Room Riddle Game built using Python and the Tkinter library. The game provides players with multiple difficulty levels, each containing a series of riddles that must be solved to unlock keys and progress further. It combines logic, pattern recognition, and time pressure to create a challenging yet engaging experience.

Features
Difficulty Levels:

Easy Mode: Single level with one riddle. Players have 3 minutes to solve it.
Medium Mode: Two levels, each with one riddle. Players have 3 minutes per riddle.
Hard Mode: Three levels with increased difficulty. Players have only 30 seconds per riddle.
Interactive Gameplay:

Players choose directions (LEFT/RIGHT/BACK) to explore the room and encounter riddles.
Clues are provided for solving riddles, which are linked to patterns, logic puzzles, or observations in the room.
Timers and Warnings:

Built-in countdown timers with warning messages for time-sensitive gameplay.
Alerts at 30 seconds and 10 seconds remaining.
Dynamic Input and Feedback:

Players input their answers to solve riddles.
Instant feedback for correct or incorrect answers.
Options to retry or continue after a wrong answer.
Replayability:

After completing or losing a game, players are prompted to play again or exit.
Technologies Used
Python: Core programming language.
Tkinter: Used for GUI development.
Pillow (PIL): For handling images (optional feature integration).
How to Play
Run the script to start the game.
Enter your name and select a difficulty level.
Follow on-screen instructions to explore the room, solve riddles, and unlock keys.
Use logical reasoning and clues provided within the game to find correct answers.
Complete all riddles in the chosen mode to win the game.
Customization and Extensions
Adding More Riddles: New riddles can be added by updating the respective functions for each mode.
Improving GUI: Enhance the visuals using custom themes, images, or animations.
Additional Modes: Introduce new difficulty levels or time constraints for added variety.
Multiplayer Mode: Allow multiple players to compete or collaborate in solving riddles.
Prerequisites
Python 3.x installed on your system.
Install the Pillow library if required: pip install pillow.
